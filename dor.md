# DOR (Definition of Ready)

- User story definida com seus critérios de aceite claros.
- User story definida com no minimo 9 casos de uso na descrição da user story do jira.
- Funcionalidades visuais devem estar bem descritas, possibilitando criação de tarefas de desing e planejamento.
- Regras de negócio relevantes documentadas.
- Cenários de sucesso/erro bem definidos para as US.
- US possuem prioridade definida e rank definidos.
- Não existem bloqueios conhecidos para iniciar o desenvolvimento
- Possuem seus requisitos pais atribuido a user story.
